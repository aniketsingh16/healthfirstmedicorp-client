Before:

After — four distinct changes inside this function:

Payload shape. deliveryMethod and paymentMethod are now sent (they were commented out, so the server had no idea what the buyer picked). cartItems sends {id, quantity} only, mapped down from cartProducts. The commented-out subtotal/tax/total stayed commented — deliberately, since the server recomputes them.
setIsPlacingOrder(true) at the top, cleared in a finally so it resets on both success and failure.
Error handling. if (!res.ok) throw sent every failure into the catch block, where it was only console.error'd — the buyer saw the button do nothing. Now it reads data.error from the response and shows it, so "3 items are out of stock" actually reaches the person.
Redirect path. /checkout/success → `/shop/success?order=${...}`. The old path 404'd; the page lives at app/(app)/shop/success/page.jsx, which serves /shop/success.
